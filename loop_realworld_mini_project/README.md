# 10 Real-World Mini Project Assignments (Medium Level)
## Python Programming • Loops and Iteration (`for` and `while` loops)

This repository folder contains 10 medium-level real-world Python mini projects focusing on iteration, conditional logic, counters, accumulators, and input validation.

---

### Project Index & Files

| Project # | Project Title | Script Filename | Key Concepts Practiced |
|---|---|---|---|
| 1 | Daily Expense Tracker | `daily_expense_tracker.py` | `for`/`while` loop, accumulator, comparison, budget threshold |
| 2 | Student Marks and Grade Report | `student_marks_and_grade_report.py` | `for` loop, counter, accumulator, `if-elif-else`, validation |
| 3 | ATM PIN Verification | `atm_pin_verification.py` | `while` loop, counter, `break`, security lockout |
| 4 | Shopping Cart Total | `shopping_cart_total.py` | `for` loop, accumulator, discount & delivery calculation |
| 5 | Number Guessing Game | `number_guessing_game.py` | `while` loop, counter, `break`, hints (`Too low`/`Too high`) |
| 6 | Electricity Usage Analyzer | `electricity_usage_analyzer.py` | `for` loop, accumulator, counter, maximum tracking |
| 7 | Employee Payroll Summary | `employee_payroll_summary.py` | `for` loop, overtime pay, tiered tax deduction, net payroll |
| 8 | Quiz Application | `quiz_application.py` | `for` loop, question collections, scoring counter, grading |
| 9 | Bank Transaction History | `bank_transaction_history.py` | `for` loop, deposit/withdrawal validation, balance tracking |
| 10 | Multiplication Table and Number Analyzer | `multiplication_table_and_number_analyzer.py` | `for` loop, `range()`, even/odd counters, range summation |
